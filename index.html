Script Cleaner

Cek landing page kamu (termasuk link pages.dev) atau tempel kode HTML manual. Deteksi & pembersihan berjalan di server (Cloudflare Pages Function), jadi bisa fetch URL apapun tanpa terkendala CORS.

URL LANDING PAGE
Bisa link pages.dev, domain custom, atau situs apapun yang HTML-nya bisa diakses publik.
TEMPEL KODE HTML
Default: tool cuma melaporkan, tidak menghapus apa pun — supaya script legit (tracking pixel, chat widget, dll) yang kebetulan cocok pola tidak ikut rusak. Review dulu daftar temuan, baru centang ini kalau mau hasil bersihnya benar-benar dipotong.
HASIL BERSIH (HTML utama)
Deteksi berbasis pola/heuristik (bukan antivirus lengkap). File .js eksternal yang terdeteksi bermasalah tidak otomatis dibersihkan (karena file itu bukan milik server ini) — kamu perlu edit source-nya sendiri lalu redeploy. Selalu review manual dan backup sebelum menimpa file production.
